# 🌤️ Weather Now

A simple and responsive weather application built with **React**, **Vite**, and **Tailwind CSS** that allows users to quickly check the current weather conditions for any city.

## 🚀 Live Demo
🔗 [Weather Now on Vercel](https://weather-app-nine-psi-50.vercel.app/)

---

## 🧠 Overview
This app lets users enter a city name and view real-time weather data — including temperature, humidity, wind speed, and a short description of conditions — fetched from a public Weather API.

---

## ⚙️ Tech Stack
- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS
- **HTTP Client:** Axios
- **Deployment:** Vercel
